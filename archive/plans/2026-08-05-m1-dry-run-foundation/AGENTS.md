# M1 Dry-Run Foundation Context

This directory contains the planned M1 implementation contract. Root `STATUS.md` decides whether
planning or any exact implementation task is active. The packet's existence never authorizes code.

## Reading order

1. Root `AGENTS.md`, `CLAUDE.md`, `SPEC.md`, `STATUS.md`, and `HANDOVER.md`.
2. Root `CLIENT-EXECUTION.md` before any client selection or launch.
3. `PACKET.md`.
4. `BUILD.md`.
5. `BUILD-TASKS.md`.
6. `STATE.md`.

## File map

| Path | Purpose |
|---|---|
| `AGENTS.md`, `CLAUDE.md` | Packet context pair |
| `PACKET.md` | M1 scope, authority, budgets, stops, validation, and acceptance |
| `BUILD.md` | Closed implementation decisions and contracts |
| `BUILD-TASKS.md` | Ordered implementation and owner-gated acceptance tasks |
| `STATE.md` | Planning and future implementation ledger; never authority |
