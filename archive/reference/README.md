# Interactive UI Reference

`square-orchestrator-interactive-reference.html` is a self-contained browser reference for the
Windows/VS Code terminal workspace, delivered with the 2026-08-07 redesign documents. It contains
its styling and interaction code, requires no development server, and can be opened directly in a
modern browser on Windows.

## Provenance note

The bootstrap build (SP00-T01..T05) and the SP00-T04 shared-UI proof were created before this file
was available to their author: several records under `docs/adr/`, `docs/proofs/`, and
`docs/receipts/` state that the HTML was "not supplied" at that time, and those records remain
accurate historical statements for the bootstrap's creation environment.

This copy is preserved as part of the merged repository. For any future SP05 shared-UI work, the
written contracts under `docs/authority/` and
`docs/superpowers/plans/2026-08-07-square-orchestrator-design/` remain authoritative; the HTML may
guide placement and interaction, but written contracts take precedence whenever presentation and
system behavior appear to conflict.
