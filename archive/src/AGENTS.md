# Archived Source Context

This grouped source tree contains the frozen pre-fork implementation. It is trace/history only;
the active fork owns live implementation work.

## File map

| Path | Purpose |
|---|---|
| `AGENTS.md`, `CLAUDE.md` | Directory context pair |
| `dotnet/` | Former .NET implementation modules |
| `sqorch/` | Former Python CLI |
| `contracts/` | Former draft public contracts and schemas |
| `prototypes/` | Former isolated architecture proofs |
| `ui/` | Former TypeScript shared UI packages |
| `vscode/` | Former VS Code extension shell |
| `tests/` | Former .NET and Python tests |
| `build/` | Former build, test, format, and package scripts |

The nested `sqorch/` and `tests/` context pairs move with their subtrees. Other nested pairs remain
owned by their original subtrees where present.
