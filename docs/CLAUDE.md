# Documentation Context for Claude

Read root `AGENTS.md`, `SPEC.md`, and `STATUS.md` first. Documentation is planning-only and must not
describe proposed behavior as shipped.

All pre-fork documentation, validation records, inventories, evidence, and superseded plans now
live under `archive/docs/` or `archive/plans/`. `docs/` retains only the active fork plan and its
context pairs. `docs/superpowers/specs/` is intentionally empty apart from its context pair until
the fork needs a new specification.

## File map

| Path | Purpose |
|---|---|
| `AGENTS.md`, `CLAUDE.md` | Documentation context pair |
| `superpowers/` | Active fork specifications and bounded plan |
