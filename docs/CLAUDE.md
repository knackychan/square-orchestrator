# Documentation Context for Claude

Read root `AGENTS.md`, `SPEC.md`, and `STATUS.md` first. Documentation is planning-only and must not
describe proposed behavior as shipped.

The pre-fork planning content formerly at `authority/`, `gates/`, `adr/`, `proofs/`, `receipts/`,
`reference/`, `SP02-T01/`, and `dispatch/` moved to `archive/` on 2026-08-09. `docs/` now retains
only the active fork plan and status records that stay up to date going forward.

## File map

| Path | Purpose |
