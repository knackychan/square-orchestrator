# Documentation Context

Root `AGENTS.md`, `SPEC.md`, and `STATUS.md` remain authoritative. Documentation may describe
planned behavior only unless the canonical specification records it as shipped.

All pre-fork documentation, validation records, inventories, evidence, and superseded plans now
live under `archive/docs/` or `archive/plans/`, consistent with the fork pivot. `docs/` retains
only the active fork plan and its context pairs. `docs/superpowers/specs/` is intentionally empty
apart from its context pair until the fork needs a new specification.

## File map

| Path | Purpose |
|---|---|
| `AGENTS.md`, `CLAUDE.md` | Documentation context pair |
| `superpowers/` | Active fork specifications and bounded plan |
