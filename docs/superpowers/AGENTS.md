# Superpowers Planning Context

This directory holds the canonical design specs and bounded execution plans. Root `STATUS.md`
decides which plan, if any, may run.

## File map

| Path | Purpose |
|---|---|
| `AGENTS.md`, `CLAUDE.md` | Planning context pair |
| `specs/` | Durable feature and architecture specifications |
| `plans/` | Time-bounded packets, build guides, task lists, and state |
