# Superpowers Planning Context

This directory holds the active fork design/specification context and bounded execution plan. Root
`STATUS.md` decides which plan, if any, may run. Superseded pre-fork specs and plans are retained
under `archive/plans/`.

## File map

| Path | Purpose |
|---|---|
| `AGENTS.md`, `CLAUDE.md` | Planning context pair |
| `specs/` | Empty fork-era specification area, with its context pair |
| `plans/` | The active `2026-08-09-fork-agent-orchestrator/` pack only |
