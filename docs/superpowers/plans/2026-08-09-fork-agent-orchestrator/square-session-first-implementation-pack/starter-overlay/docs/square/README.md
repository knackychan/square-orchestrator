# Square Downstream Documentation

This directory is owned by the Square fork. Official Agent Orchestrator documentation remains under the upstream paths.

- `authority/` — accepted, hashed product and implementation authorities.
- `adr/` — Square architecture decisions.
- `upstream/` — pinned baseline and upstream-sync records.
- `evidence/` — raw task/gate evidence.
- `receipts/` — completion and gate receipts.
- `gates/` — reviewed gate decisions.
- `plans/` — task packets copied from accepted authority.
- `templates/` — dispatch/evidence/receipt templates.

Do not edit an accepted authority document in place. Create a versioned amendment and update the authority manifest after owner acceptance.
