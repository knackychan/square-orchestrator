# Owner Decisions Before and During Implementation

## Required before SA00-T01

- [ ] Destination path for the fork.
- [ ] Owner remote URL, or explicit decision to add it later.
- [ ] Product name remains **Square Orchestrator**.
- [ ] Primary user command remains **square**.
- [ ] Accept AO stable `v0.12.1` / commit prefix `1df40e9` as the starting baseline.
- [ ] Accept the maintained-fork model and Apache-2.0 attribution obligations.

## Required before SA00-T04/A0

- [ ] Accept or amend `docs/ARCHITECTURE_AMENDMENT.md`.
- [ ] Accept the session-first UI as the primary product model.
- [ ] Accept deterministic Go Task Manager versus a persistent monitoring model.
- [ ] Accept AO HTTP/SSE/WebSocket as provisional MVP transport.
- [ ] Accept Windows x64 first.
- [ ] Accept telemetry off by default.
- [ ] Accept official AO updater disabled/replaced before Square distribution.
- [ ] Select Square data, run-file, worktree, Electron userData, package/app IDs.
- [ ] Decide official AO coexistence/import policy.

## Required by A2 contracts

- [ ] Default workflow setting: AUTO, QUICK, or confirmation for every session.
- [ ] Role routing presets: Economy, Balanced, Quality, Manual, Project Default.
- [ ] Default role profiles for Secretary, Scout, Planner, Orchestrator, Worker, Reviewer.
- [ ] PINNED unavailability behavior remains fail-closed.
- [ ] Reviewer independence default and owner-exception authority.
- [ ] Context warning/handover/hard ceilings.
- [ ] Default writer/read-only permissions and network policy.
- [ ] Local-result versus PR-result default.

## Required before A6 UI integration

- [ ] Approve the rounded light/dark token direction.
- [ ] Confirm session tabs/list/new-session composer as the global shell.
- [ ] Decide initial docking library only after license/accessibility/performance proof.
- [ ] Decide whether the first UI supports user drag/drop or fixed responsive layouts.
- [ ] Default terminal history retention.
- [ ] Direct attention actions shown without extra inspector navigation.

## Required before A7 real QUICK Alpha

- [ ] Select first installed route after certification evidence.
- [ ] Approve disposable real-task fixture/repository.
- [ ] Decide whether every Dispatch Preview needs owner approval initially.
- [ ] Decide local-result/branch/PR integration policy for Alpha.

- [ ] PLANNED plan-approval authority.
- [ ] Maximum automatic FIX iterations.
- [ ] Independent reviewer exception policy.
- [ ] Final acceptance authority.

- [ ] Release repository/feed/channel.
- [ ] Code signing and installer identity.
- [ ] Update/rollback policy during active work.
- [ ] Support-bundle redaction defaults.
- [ ] Official AO state import UX.
