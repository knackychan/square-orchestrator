# SA00-T01 — Create and pin the downstream fork

- Phase: SA00 — Fork adoption and reproducible baseline
- Gate contribution: A0
- Status: ready for owner dispatch
- Expected implementation mode: one fresh local coding-agent session
- Expected code change: governance/bootstrap only; no Square product behavior

## 1. Objective

Create a verifiable downstream Git fork of Agent Orchestrator stable `v0.12.1`, preserve its exact upstream identity, establish the Square branch/remotes/baseline tag, and add only the minimum governance/evidence structure needed to measure the unchanged source in SA00-T02.

The task must not rebrand the app, change dependencies, run migrations, alter package metadata, modify daemon behavior, or add Square domain/UI code.

## 2. Authority

Read completely before acting:

1. `plans/MASTER_IMPLEMENTATION_PLAN.md`
2. `docs/ARCHITECTURE_AMENDMENT.md`
3. `docs/UPSTREAM_GOVERNANCE.md`
4. `source-map/AO_SOURCE_PLACEMENT_MAP.md`
5. this task packet
6. `scripts/bootstrap-square-fork.ps1`

The pinned source target is:

```text
repository: https://github.com/Untrivial-ai/agent-orchestrator.git
tag:        v0.12.1
commit:     must begin with 1df40e9 and exactly equal v0.12.1^{commit}
```

## 3. Required owner inputs

Before execution, obtain:

- absolute destination path for the new fork;
- optional downstream Git remote URL;
- absolute path to this implementation pack when the curated `starter-overlay` should be copied;
- owner instruction on whether the task agent may create the first commit;
- Git author identity already configured locally.

Do not ask for a remote URL when the owner intends to work locally first. The task may complete without an `origin` remote.

## 4. Preconditions

- Windows PowerShell 5.1 or PowerShell 7 is available.
- Git is available on `PATH`.
- Destination does not exist or is empty.
- Network access to the selected upstream remote is permitted.
- No source ZIP is used in place of Git history.
- The task agent has not begun from a previously modified AO checkout.

```text

LICENSE
NOTICE*
```

Do not:

- push any branch or tag;
- rewrite or squash upstream history;
- delete the upstream remote;

- create a GitHub fork through an account connector unless explicitly instructed;
- install dependencies;
- run code generation;
- change line endings repository-wide;
- run formatters that touch upstream files;
- rebrand or disable telemetry/updater yet;
- add Square source code.

## 8. Required implementation

Use the supplied bootstrap script after reviewing it:

```powershell
& "<PACK>\scripts\bootstrap-square-fork.ps1" `
  -Destination "<DESTINATION>" `
  -OriginUrl "<OPTIONAL-DOWNSTREAM-REMOTE>" `
  -AuthorityPackPath "<PACK>"
```

Omit `-OriginUrl` when no remote is ready. `-AuthorityPackPath` copies only the curated starter overlay and does not activate the full authority set; SA00-T04 performs the owner-approved authority import.

The implementation must establish:

```text
upstream          → official Agent Orchestrator repository
square/main       → downstream integration branch
square-base-v0.12.1 → annotated tag on exact untouched upstream commit
origin            → optional owner downstream repository
```

Create `docs/square/upstream/initial-baseline.json` with:

- schema version;
- upstream URL;
- upstream tag;
- full upstream commit;
- Square branch;
- baseline tag;
- UTC creation timestamp;
- explicit `pushed: false`.

When the starter overlay is copied, preserve its bytes and directory structure. It contains only governance staging files; accepted authority is imported later by SA00-T04.

## 9. Verification commands

Run from outside or inside the new repository as appropriate:

```powershell
git -C "<DESTINATION>" rev-parse HEAD
git -C "<DESTINATION>" rev-parse "v0.12.1^{commit}"
git -C "<DESTINATION>" rev-parse "square-base-v0.12.1^{commit}"
git -C "<DESTINATION>" branch --show-current
git -C "<DESTINATION>" remote -v
git -C "<DESTINATION>" status --short
git -C "<DESTINATION>" log -1 --decorate --oneline
git -C "<DESTINATION>" show-ref --tags --dereference
```

Required assertions:

- all three commit resolutions are identical;
- branch is `square/main`;
- `upstream` resolves to the intended source URL;
- `origin`, if configured, resolves exactly to the owner-provided URL;
- no upstream tracked source file differs from the pinned commit;
- only `docs/square/**` may be untracked/modified;
- no push has occurred.

Compare tracked files against the baseline:

```powershell
git -C "<DESTINATION>" diff --name-only "square-base-v0.12.1" -- `
  backend frontend packages package.json package-lock.json .github
```

Expected output: empty.

## 13. Mandatory STOP conditions

Stop without improvising when:

1. `v0.12.1` resolves to a commit not beginning with `1df40e9`.
2. HEAD and tag target differ.
3. the destination contains files or a different Git repository.
4. the upstream source cannot be fetched and independently resolved.
5. the owner-provided origin already contains unrelated history requiring a force push.
6. the bootstrap would overwrite local files.
7. the task requires changing upstream source to complete.
8. license/NOTICE files are absent or unexpectedly altered.
9. Git reports corruption, unsafe repository ownership, or an unresolved filesystem problem.
10. a credential appears in a remote URL or evidence file.

A STOP report must include the exact command, output, current paths, and safe owner options. It must confirm that no fallback source ZIP, alternate tag, or force operation was used.

## 14. Acceptance criteria

- **SA00-AC-01:** the downstream checkout has exact, reproducible upstream identity.
- **SA00-AC-02:** `square-base-v0.12.1` points to untouched upstream source.
- **SA00-AC-03:** `square/main` exists and `upstream` remains configured.
- **SA00-AC-04:** no product source or dependency file differs from upstream.
- **SA00-AC-05:** governance/evidence paths exist and are hashable.
- **SA00-AC-06:** no remote push occurred.
- **SA00-AC-07:** the task receipt and evidence manifest are complete.
